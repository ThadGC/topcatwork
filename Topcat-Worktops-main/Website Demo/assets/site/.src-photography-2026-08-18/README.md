# The photographic masters — moved off the site 18 August 2026 (D315)

Every file here is the **source a live WebP ladder was cut from**. Nothing on the site asks for
any of them: the pages serve the rungs (`why-team-900.webp`, `cta-slab-2752.webp`, and so on) and
have done since the image-optimisation round. They were still being uploaded to the host, so the
client was paying for 15 MB of photography no browser ever requested.

⛔ **DO NOT DELETE.** A rung can be re-cut from a master; a master cannot be re-cut from a rung.
This is the same reason `.src-2026-08-17/` keeps `hero-night-source.png`.

⭐ **This folder is dot-prefixed, so `make_upload.py` will not ship it** — the rule from D314 is
that any dot-prefixed FOLDER is workshop, not site.

⚠️ Two of these did not come from `assets/site/` — `cta-slab.jpg` and `quarry.jpg` sat at
`assets/` root, one directory above their own rungs. They are here with the rest now.
