# Gallery frames deliberately left out of their project — 18 August 2026 (D315)

These five were cut but never put in a `gallery:[…]` array in `index.html`, so no page has ever
shown them. They were still being uploaded.

⭐⭐ **`hornchurch-g2` and `hornchurch-g3` are the two the client pulled by name**, 14 Aug 2026:
the old `-g2` was a slab on a trolley in a dusty workshop with an air hose across the floor, and
the old `-g3` a half-built room with a stepladder, a mitre saw and loose cables. Client:
*"if something doesn't look good, don't use it."*

`hornchurch-g6`, `harlow-g7` and `rickmansworth-g16` were never in an array either — no note
records why, which is worth knowing before assuming they are bad frames.

⭐ **TO RESTORE ANY OF THEM**: move the file back up to `assets/projects/` and put its path into
that project's `gallery:` array in `index.html`. The array is the only thing that decides.
